# Lamsaty Hoodie Studio (لمستي)

An online storefront for a custom hoodie brand: browse the collection, design your own hoodie, manage a cart, and edit products from an admin dashboard.

## Pages

| Route | What it does |
| --- | --- |
| `/` | Landing page with hero, featured products and a custom-design call to action |
| `/shop` | Full product catalogue |
| `/custom` | Order a hoodie with your own design |
| `/cart` | Shopping cart |
| `/contact` | Contact form |
| `/admin/login`, `/admin/dashboard` | Add and edit products (name, price, image) |

## Tech stack

React 18 · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router

## Run locally

```bash
npm install
npm run dev
```

> The admin login is a front-end demo only (no backend auth), so this is a portfolio prototype, not a production shop.
